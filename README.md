# Задания на микросервисы платформы наружной рекламы

Три независимых сервиса, каждый - отдельная команда и отдельный репозиторий. Платформа
разговаривает с сервисом только по HTTP; код платформы вам не нужен, всё необходимое здесь.

Порядок чтения:

1. `common-requirements.md` - общие правила для всех сервисов: контракт HTTP, поставка в Docker,
   безопасность, процесс по этапам M0-M3, порядок приёмки. Читать первым, целиком.
2. `<номер>-<сервис>/brief.md` - задание вашего сервиса: контекст, что должен уметь, ограничения,
   что сдать, как принимаем.

| Папка | Сервис | Коротко |
|---|---|---|
| `01-geo-layers/` | Гео-слои | Сетки данных поставщиков и наборы точек → тайлы-подложки для карты, легенды, значения и агрегаты, тепловые карты. В `samples/` - первые объекты образца, `layers_sample_2023Q1.zip` - полный образец |
| `02-creative-analysis/` | Анализ креативов | Метаданные файлов, проверка против требований носителя, поиск рискованного содержания, превью и перекодирование, S3 |
| `03-speech-analysis/` | Анализ речи | Расшифровка разговоров и коротких голосовых запросов строго локально, разбор и сводная аналитика |

Рекомендую начинать с design doc  (границы, черновик API, схема данных, стек с
обоснованием, план)
